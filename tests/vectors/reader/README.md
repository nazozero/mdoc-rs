# Reader authentication fixture

`reader_authentication.tsv` contains project-owned synthetic bytes generated by
`generate.py` with Python cryptography 50.0.0 and its OpenSSL backend. The
generator independently encodes the ISO request, transcript, tagged
ReaderAuthentication and COSE Sig_structure, then signs with deterministic
ECDSA P-256. The Rust test compares the exact signing input and completes the
external signature; changed signatures and transcript bytes must fail.

The certificate carries the reader-authentication EKU. It is a public test
identity, not an admitted trust anchor. The generator's private scalars are
public fixtures. These files use the repository's BSD-2-Clause license.

Regenerate with `python tests/vectors/reader/generate.py`. Tests use the checked-in
bytes and need no Python runtime.
